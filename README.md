# Reproducibility Package

Code and anonymized data for:

**Benchmarking under Supplier Cold Start: A Layered Computational Market Approach to Data Asset Pricing**

## Program

The empirical analysis is reproduced with one standalone Python program:

```text
run_paper_all_from_raw_standalone_with_excel.py
```

The program reproduces the manuscript's descriptive analysis, global benchmark evaluation, local comparable retrieval, Bayesian reconciliation, ablation analyses, robustness checks, manuscript tables, and empirical figures.

All fold-dependent representation learning, model tuning, comparable retrieval, and uncertainty estimation use training-fold information only.

## Inputs

The program uses two input files:

```text
price_files/dataproduct_industry_analysis_list_format_anymous.xlsx
export_neo4j/api_data_snapshot.csv
```

The Excel file provides the analytical sample, including standardized posted quotes, original CNY quotes, product text, supplier information, and ontology-category information.

The CSV file provides the corresponding knowledge-graph relations and product ordering used to reconstruct graph representations within each validation fold.

**The released data are anonymized at the data-asset and supplier level. This is intended to reduce re-identification Risk and to accommodate possible Data-Security and compliance Requirements Applicable to Data-related Information in China. The anonymization preserves the empirical structure required for reproduction.**

## Reproduction

From the repository root, run:

```bash
python run_paper_all_from_raw_standalone_with_excel.py
```

With the repository structure shown above, no command-line arguments are required.

The full manuscript analysis uses the program defaults, including five-fold KFold and supplier-grouped GroupKFold validation, 5,000 paired-bootstrap replications, and three matched graph-validation repeats per fold.

For a quick code-path check only:

```bash
python run_paper_all_from_raw_standalone_with_excel.py --max-folds 1
```

The smoke test does **not** reproduce the full manuscript results.

For exact reproduction of the reported results:

- use the supplied input files without altering their contents;
- use the default program settings unless a deviation is explicitly documented;
- do not treat smoke-test or reduced-bootstrap runs as manuscript reproduction;
- if the code, parameters, inputs, or execution environment are modified, report those changes when presenting derived results.

## Outputs

All outputs are written to:

```text
paper_result_final/
```

The consolidated manuscript workbook is:

```text
paper_result_final/paper_results_tables/All_Tables_Main_and_Apppendix.xlsx
```

`paper_results_tables/` contains the manuscript tables and consolidated workbook.

`paper_results_figures/` contains Fig. 3 and the empirical appendix figures in PNG and PDF formats.

`paper_results_intermediate/` contains intermediate predictions, validation results, diagnostics, and audit files used to construct the reported results.

Manuscript Fig. 1 and Fig. 2 are conceptual/schematic figures and are not generated by the empirical reproduction program.
